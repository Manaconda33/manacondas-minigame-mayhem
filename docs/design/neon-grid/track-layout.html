CIRCUIT 02 · ROUTE NIGHT · TOP-DOWN LAYOUT GUIDE — NOT TO SCALE, FLOW OVER PRECISION
Sector 1 — fast, boost pads Sector 2 — technical, hairpins Sector 3 — falls, jump finish Hidden shortcut Token
Build notes: Direction is clockwise from START/FINISH. Sector 1 is wide expressway (room for 4-wide racing); Sector 2 narrows to alley width (2-wide, walls both sides); Sector 3 re-widens with the waterfall jump gap on the west climb. Shortcuts are skill-gated, never luck-gated: (1) billboard always smashable, flicker-off = clean exit speed, flicker-on = static slowdown; (2) tunnel is narrow but walled — the test is line choice, not survival; (3) dive is a real ramp jump — land it or splash down and respawn on-track with a modest penalty. One token inside each shortcut rewards discovery before mastery.

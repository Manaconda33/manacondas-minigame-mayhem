# Neon Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task by task under native execution. Steps use checkbox syntax. Manny may choose another execution method at the plan review.

**Goal:** Build Neon Grid as Circuit 02: a selectable, approximately 1.40–1.50 km neon-city race with three distinctive sectors and three learnable shortcuts.

**Architecture:** Introduce a small shared track contract while retaining the existing race, lap, item, physics, and roster authorities. Give Neon Grid its own scene and collision builders; reuse shared rendering primitives and resource disposal. Shortcut traversal maps a racer's actual position to main-route progress and never grants checkpoints.

**Tech Stack:** Existing Vite, TypeScript, Three.js, Rapier, Web Audio/Howler, Vitest, and GitHub Pages. No new dependency is planned.

**Spec:** `docs/design/neon-grid/NEON-GRID-SPEC.md`; read the adjacent `README.md`, `track-layout.html`, and both visual-reference JPEGs.

## Global constraints

- Product name: `Manaconda's Minigame Mayhem`; Route Night UI grammar; GitHub Pages hosting.
- Race format: player plus seven unique AI drivers, three validated laps, existing approved roster/stat/item values.
- Main curve: closed centripetal Catmull–Rom, 384 samples, 12 ordered checkpoints, starting grid origin separate from the finish crossing by 22 m.
- Sector road half-widths: Skyline 6 m, Undercity 4.5 m, Falls Run 6 m; Service Tunnel 3.2 m. Interpolate authored main-road width transitions.
- Elevation: Skyline deck approximately 14 m, Undercity approximately 0 m, Falls Run climbs toward 14 m.
- Clean main-route lap target: 62–68 seconds; sampled course length target: 1.40–1.50 km. Measure both; coordinate scaling alone is not evidence.
- Shortcut savings: Billboard 0.6–0.9 s, Tunnel full-hairpin bypass saving to be measured, Dive 1.8–2.2 s; these require controlled measurements.
- Billboard: always passable, 6-second cycle, 4 seconds ON / 2 OFF, 0.8-second tell before either switch; ON shortcut speed multiplier 0.82.
- Dive miss: splash and on-track recovery with an approximately 1.5-second penalty, before the downstream checkpoint.
- Accepted Circuit Alpha behavior, assets, audio, UI, prior previews, and acceptance records stay covered by regression checks.
- Follow `AGENTS.md`, `.gitattributes`, `docs/LFS-PUBLISHING.md`, and asset approval/provenance rules. The supplied JPEGs are design references, not runtime assets.

## Review focus

1. Nearby road at another elevation must not acquire a checkpoint or surface through planar proximity. Task 3 tests stacked deck/street crossings and height-aware gates.
2. Shortcut projection must remain on the chosen path after entry, including reversing, pausing, and recovery. Tasks 5–7 test traversal lifecycle and all eight shortcut combinations.
3. AI and Rocket must follow legal physical routes without progress, transform, or rank jumps. Tasks 4–7 test real controller traversal and item routes.
4. Replay, route switching, hidden tabs, and pause must release/freeze geometry, colliders, shortcut timers, effects, and audio. Tasks 4, 6, 7, 9, and 10 test lifecycle.
5. Bright city/waterfall effects must leave road edges and driver actions readable on mobile at Low/Medium/High. Task 9 provides rendered review and quality-budget evidence.

## Interpretation boundaries

The image is authoritative for visual composition, formatting, information density, hierarchy, panel geometry, typographic behavior, accent relationships, cinematic framing, Character Select presentation, in-race HUD organization, and results/podium staging.

It is **not** roster authority. Characters shown in the concept are placeholders; production uses the approved game roster, portraits, driver art, names, stats, and kart identities.

It is **not** a universal nighttime-track requirement. Circuit Alpha retains its authored presentation, and future tracks may use unique time-of-day, lighting, sky, weather, and environmental palettes while the Route Night UI grammar remains consistent.
